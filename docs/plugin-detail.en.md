## Get started

1. Install and sign in to your Agent on the computer running DSH.
2. **Add Agent** below, save, then **Re-check** the connection.
3. Start a new session and choose the Agent and model in the model menu.

Standard mode works with ACP Agents. Choose **Creator mode** to create plugins. The optional **ACP** mode lets the Agent manage conversation context.
