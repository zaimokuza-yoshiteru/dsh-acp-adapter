# DSH RC.4 开放问题评估

2026-11-18 核对了插件仓库全部 8 个开放 issue、相关评论、插件实现和 DSH RC.4 源码。建议优先修 #87，单独评审 #86 的策略覆盖范围。#74、#78 已有对应发行版本，建议关闭；此次核查未在 GitHub 上关闭或修改任何 issue。下列判断依据源码、已有用例和发行记录，真实 Agent 复现范围按各项注明。
