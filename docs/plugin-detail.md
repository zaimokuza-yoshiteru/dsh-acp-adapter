## 开始使用

1. 在运行 DSH 的电脑上安装并登录要使用的 Agent。
2. 在下方**添加 Agent**，保存后点击**重新检查**。
3. 新建会话，在模型菜单选择 Agent 及模型。

标准模式可直接使用 ACP Agent。创建插件请选择**创造模式**；**ACP** 是由 Agent 管理对话上下文的可选模式。
